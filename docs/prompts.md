# Примеры запросов

Замените квадратные скобки своими сведениями. Неизвестное можно прямо так и назвать. Для всех запросов действует режим чтения; разрешение исправлять продукт нужно давать отдельно.

## До первого запуска

```text
Используй $check-ru-digital-product. Готовлю к запуску [описание продукта]
для [аудитория, страна]. Стадия: проект ещё не запущен.
Продавец и оператор: [известные сведения].
Планируемые данные и оплаты: [описание]. Материалы: [файлы].
Изучи план на чтение и проверь актуальные источники.
Что выяснить или подготовить до начала сбора данных и первой оплаты?
Не выдавай планируемую функцию за работающую.
```

## Страница с аналитикой и видео

```text
Используй $check-ru-digital-product. Проверь только обработку данных
на [URL] по коду, политике и приложенной обезличенной записи браузера.
Ничего не запускай и не меняй. Сопоставь подключения до выбора,
после отказа, принятия и отзыва. Отдельно отметь, что запись
не покрывает. Не делай вывод о стране хранения по имени домена.
```

## Подписка и отмена

```text
Используй $check-ru-digital-product. Проверь сценарий подписки:
[что продаём, кому, кто продавец, как происходят списания].
Приложены оферта и описание интерфейса отмены.
Разбери продление, прекращение договора и возврат по отдельности.
Проверь действующие источники. Нужны замечания и план проверки
исправлений; готовую оферту не составляй. Работай на чтение.
```

## Достаточно ли доказательств защиты

```text
Используй $check-ru-digital-product. Оцени только доказательства
отзыва доступа и восстановления резервной копии в этом
обезличенном пакете. Что подтверждено, чего не хватает и как
закрыть конкретный пробел? Не делай общий вывод о законности.
Не запускай восстановление, не меняй доступы и не выполняй пентест.
```

## Когда нет интернета

```text
Используй $check-ru-digital-product. Доступа к интернету нет.
По этому обезличенному описанию составь карту вопросов для
следующей проверки. Не называй нормы и суммы актуальными без
проверки источников. Ничего не меняй и не отправляй.
```
