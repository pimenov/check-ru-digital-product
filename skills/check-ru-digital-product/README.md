# Правовая проверка цифрового продукта

`check-ru-digital-product`, версия 1.1.1. Автор: Сергей Пименов / [pimenov.ai](https://pimenov.ai).

Скилл для Codex: проверка доступных материалов сайта, приложения, SaaS или бота
по вопросам данных, платежей и договорных условий для работы с пользователями
в России. Проверяет источники на дату задачи, отделяет факты от неизвестного,
возвращает замечания с доказательствами и план действий. Работает на чтение.
Отчёт начинается с простого объяснения и конкретного первого шага для владельца;
доказательства, ограничения и источники идут следом в том же ответе.

Публичный репозиторий с установкой и примерами: [pimenov/check-ru-digital-product](https://github.com/pimenov/check-ru-digital-product).

## Установка и запуск

Поместите весь каталог `check-ru-digital-product` в `skills/` активного Codex home
(обычно `~/.codex/skills/`). Сохраните вложенные файлы и LICENSE. В новой сессии
вызовите `$check-ru-digital-product` и укажите проект, область проверки и
обезличенные материалы. Автоматический выбор по подходящему запросу разрешён.

Для текущих правовых выводов нужен доступ к веб-источникам. Если его нет,
результат ограничивается разбором материалов и вопросами для проверки.
Дополнительные пакеты, ключи и исполняемые скрипты скиллу не нужны.
Для проверки браузерного поведения нужны разрешённая тестовая среда и доступные
браузерные инструменты либо обезличенная запись сетевых запросов и состояний.
Без них скилл проверяет код и документы, но не заявляет, что поведение проверено.

Пример: «Используй $check-ru-digital-product. Проверь оплату подписки и отмену
продления в этом проекте для российских потребителей. Изучи код и оферту,
ничего не меняй. Для каждого замечания укажи источник и способ проверки исправления».

## Проверки и границы

Учебные случаи находятся в `evals/`. Это воспроизводимые задания с критериями,
а не обещание юридической точности на произвольном продукте. Критерии правовых
ответов перепроверяются по текущим источникам при повторном прогоне.

Скилл не выдаёт разрешение на запуск, не подаёт уведомления и не исправляет
продукт без отдельного поручения. Специальные и международные вопросы обозначает
для отдельной квалификации. Не передавайте клиентские базы и секреты.
Включены сценарии согласия, учёт внешних подключений, доказательства защиты данных
и разбор применимости санкций. Технический аудит уязвимостей и пентест не входят.
